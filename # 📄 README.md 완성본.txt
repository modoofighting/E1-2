## 5. 기능 설명

### 1️⃣ 퀴즈 풀기 (전체)

- 저장된 퀴즈를 **순서대로** 모두 풀기
- 문제마다 1~4번 중 선택
- 게임 종료 후 **정답 수 · 오답 수 · 점수** 출력
- 최고 점수 갱신 시 알림 표시
- 결과는 **자동 저장**

### 2️⃣ 퀴즈 풀기 (난이도별)

- **쉬움 / 보통 / 어려움** 중 선택
- 선택한 난이도의 퀴즈만 필터링하여 출력
- 해당 난이도 퀴즈가 없으면 안내 메시지 출력

### 3️⃣ 퀴즈 추가

- 문제 · 선택지 4개 · 정답 번호 · 난이도 · 카테고리 직접 입력
- 추가 즉시 **자동 저장**

### 4️⃣ 퀴즈 목록

- 전체 퀴즈를 번호 · 카테고리 · 난이도 · 정답과 함께 출력

### 5️⃣ 퀴즈 삭제

- 목록에서 번호를 선택하여 삭제
- 0번 입력 시 취소
- 삭제 즉시 **자동 저장**

### 6️⃣ 점수 / 통계 확인

| 항목 | 설명 |
|------|------|
| 총 게임 횟수 | 지금까지 플레이한 횟수 |
| 총 정답 개수 | 누적 정답 수 |
| 총 오답 개수 | 누적 오답 수 |
| 전체 정답률 | 정답 / 전체 × 100 |
| 최고 점수 | 한 게임에서 받은 최고 점수 |

## 7. 클래스 구조

### Quiz 클래스

```python
class Quiz:
    # 퀴즈 1개를 표현하는 클래스

    속성
    ├── question   : 문제 텍스트
    ├── choices    : 선택지 리스트 (4개)
    ├── answer     : 정답 번호 (1~4)
    ├── difficulty : 난이도 (쉬움/보통/어려움)
    └── category   : 카테고리 (Python/Git 등)

    메서드
    ├── show()          : 문제 + 선택지 출력
    └── check(answer)   : 정답 여부 반환 (True/False)
```

### QuizGame 클래스

```python
class QuizGame:
    # 게임 전체를 관리하는 클래스

    속성
    ├── quizzes    : 퀴즈 목록 (리스트)
    ├── best_score : 최고 점수
    └── stats      : 통계 딕셔너리
                     ├── total_played
                     ├── total_correct
                     └── total_wrong

    메서드
    ├── show_menu()            : 메뉴 출력
    ├── get_choice(min, max)   : 숫자 입력 검증
    ├── play()                 : 전체 퀴즈 풀기
    ├── play_by_difficulty()   : 난이도별 퀴즈 풀기
    ├── add_quiz()             : 퀴즈 추가
    ├── show_list()            : 퀴즈 목록 출력
    ├── delete_quiz()          : 퀴즈 삭제
    ├── show_score()           : 통계 출력
    ├── save()                 : 파일 저장 (pickle)
    ├── load()                 : 파일 불러오기 (pickle)
    └── run()                  : 게임 메인 루프
```
