## 🔨 STEP 2: Git 저장소 만들기

### 순서
```
1. GitHub에서 새 저장소(repository) 생성
2. 내 컴퓨터에 폴더 만들기
3. 그 폴더를 Git 저장소로 초기화
4. GitHub 저장소와 연결
```

### 실제 명령어
```bash
mkdir quiz-game          # 폴더 만들기
cd quiz-game             # 폴더 들어가기
git init                 # Git 저장소 초기화
git remote add origin [GitHub URL]  # GitHub 연결
```

#### 덩어리 5️⃣: 파일 저장/불러오기
**뭐냐?** → 프로그램 꺼도 데이터가 남도록

```python
import json

# 저장
def save(self):
    data = {
        "quizzes": [...],   # 퀴즈 목록
        "best_score": 80    # 최고 점수
    }
    with open("state.json", "w", encoding="utf-8") as f:
        json.dump(data, f)

# 불러오기
def load(self):
    try:
        with open("state.json", "r", encoding="utf-8") as f:
            data = json.load(f)
    except FileNotFoundError:
        # 파일 없으면 기본 데이터 사용
        pass
```

#### 덩어리 6️⃣: 예외 처리
**뭐냐?** → 잘못된 입력해도 프로그램이 안 죽도록

```python
# 예시: 숫자만 받기
while True:
    user_input = input("선택: ").strip()
    if user_input == "":
        print("⚠️ 입력이 없습니다.")
        continue
    try:
        choice = int(user_input)
        if 1 <= choice <= 5:
            break
        else:
            print("⚠️ 1-5 사이 숫자를 입력하세요.")
    except ValueError:
        print("⚠️ 숫자를 입력하세요.")
```

## 🔨 STEP 4: Git 커밋 계획 (10개 이상)

| 커밋 번호 | 작업 내용 | 커밋 메시지 예시 |
|-----------|-----------|-----------------|
| 1 | 초기 파일 생성 | `Init: 프로젝트 초기 설정` |
| 2 | Quiz 클래스 | `Feat: Quiz 클래스 구현` |
| 3 | 기본 퀴즈 데이터 | `Feat: 기본 퀴즈 5개 추가` |
| 4 | 메뉴 기능 | `Feat: 메뉴 출력 및 선택 기능` |
| 5 | 퀴즈 풀기 | `Feat: 퀴즈 풀기 기능 구현` |
| 6 | 퀴즈 추가 | `Feat: 퀴즈 추가 기능 구현` |
| 7 | 퀴즈 목록 | `Feat: 퀴즈 목록 보기 기능` |
| 8 | 점수 기능 | `Feat: 최고 점수 저장/확인` |
| 9 | 파일 저장 | `Feat: JSON 파일 저장/불러오기` |
| 10 | 예외 처리 | `Fix: 잘못된 입력 예외 처리` |

### 브랜치 작업 (필수 1회)
```bash
git checkout -b feature/quiz-play   # 새 브랜치 생성
```

## 🔨 STEP 6: clone/pull 실습

```bash
# 다른 폴더에 복제
git clone [GitHub URL] quiz-game-copy

# 복제된 폴더에서 수정 후 push
cd quiz-game-copy
# README 한 줄 추가 후
git add README.md
git commit -m "Docs: README 한 줄 추가"
git push

# 원래 폴더에서 변경사항 가져오기
cd ../quiz-game
git pull
```
